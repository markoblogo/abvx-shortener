# ABVX Shortener v0.3

## Что добавилось

- Операционный слой управления: `GET /api/stats`, `GET /api/links`, `POST /api/links/bulk`, `GET /api/links/export`, `GET /api/events`.
- Поддержка приватных ссылок и расширенные redirect-параметры: `redirectType`, `fallbackUrl`, `private`, `privateTokenRequired`.
- Trust/role модель: `TRUST_MODE` + `API_KEYS_JSON`.
- Расширенные ограничения целевых URL: allow/deny домены и optional URL precheck hook.
- Наблюдаемость: KV-метрики, audit-log событий и Cloudflare Workers Logs.
- Нативный Cloudflare rate limiter для production и неблокирующая запись redirect-метрик.
- Расширение расширения: background service worker, контекстное меню, commands, omnibox.
- Операционный CLI: `bin/abvx-shorten`.

## Конфигурация Worker

| Переменная | Описание |
| --- | --- |
| `TRUST_MODE` | `personal` | `readonly` | `readonly-create` |
| `ALLOW_URL_DOMAINS` | Список доменов для allowlist целевых ссылок (через запятую) |
| `DENY_URL_DOMAINS` | Список доменов для denylist целевых ссылок |
| `URL_PRECHECK_URL` | Опциональный URL precheck-Webhook |
| `URL_PRECHECK_TIMEOUT_MS` | Таймаут precheck (default `1500`) |
| `URL_PRECHECK_FAIL_OPEN` | `true|false` (доступ по умолчанию при падении precheck API) |
| `API_KEYS_JSON` | Секрет с массивом `{ id, role, secret|secret_hash }` |
| `DEFAULT_REDIRECT_TYPE` | `302` по умолчанию, `301` альтернативно |

`API_KEYS_JSON` при чтении:

```json
[
  { "id": "writer-1", "role": "writer", "secret_hash": "sha256:HEX_DIGEST" }
]
```

## API-слой v0.3

### `GET /api/stats`

Параметры: `window=minute|hour|day`, `since`, `until`.

Возвращает унифицированные счетчики:
`redirect_hit`, `redirect_miss`, `expired_hit`, `disabled_hit`, `api_conflict`, `rate_limited`, `created`, `updated`, `deleted`, `private_denied`.

### `GET /api/links`

Cursor pagination + фильтры:

- `cursor`
- `limit` (по умолчанию `50`, максимум `200`)
- `disabled`/`expired`/`customSlug`
- `createdBy`/`q`

### `POST /api/links/bulk`

Тело: `action=disable|restore|delete`, `slugs`, `dryRun`.

### `GET /api/links/export`

`format=json|csv`, те же фильтры, плюс `cursor`, `limit`.

### `GET /api/events`

Cursor pagination для immutable audit events (`create`, `update`, `delete`, `soft-delete`, `restore`).

## Redirect-поведение

Для `GET /:slug` поддерживаются:

- `redirectType`: `301` или `302` (по умолчанию из конфига)
- `fallbackUrl`: редирект при `410/404` для expired/disabled
- `private`: доступ по действующему `X-API-Key`
- `privateTokenRequired`: доступ только создававшему ссылку ключу или admin

`Accept` и `Prefer` учитываются через единый envelope ответа:
- JSON для API клиентов
- HTML fallback для браузерных вызовов

## Важное соглашение

- При наличии `API_KEYS_JSON` legacy `API_KEY` не используется; некорректная конфигурация блокирует доступ.
- v0.3 оставляет KV как fast-path для redirect.
- События и метрики — best-effort/approximate and bounded by KV TTL retention.
